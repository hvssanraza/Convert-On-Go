# ConvertOnGo

> Fast, simple, and secure file conversion directly in your browser.

🌐 Website: https://convertongo.com

---

## 🚀 About

ConvertOnGo is a modern web-based file conversion platform built to provide quick, efficient, and user-friendly file conversion tools. The project focuses on performance, simplicity, and accessibility while maintaining a clean and responsive interface.

The goal of ConvertOnGo is to make file conversion seamless for everyone — directly from the browser without unnecessary complexity.

---

## ✨ Features

* ⚡ Fast file conversion
* 🎨 Clean modern UI
* 📱 Fully responsive design
* 🔒 Secure HTTPS connection
* 📂 Drag & drop upload support
* 🚀 Lightweight and optimized
* 🌙 Minimal user experience

---

## 🛠️ Tech Stack

* HTML5
* CSS3
* JavaScript
* GitHub Pages

---

## ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/hvssanraza/Convert-On-Go.git
```

Open the project folder:

```bash
cd Convert-On-Go
```

Run locally by opening `index.html` in your browser.
